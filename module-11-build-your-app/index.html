Module 11

Build Your App with Copilot

An app lets people enter data and act on it. Microsoft Copilot gives you more than one way to make an app. In this module, you learn what an app is. Then you compare the ways to make one, and you build an app with Code.

11.1 Anatomy of an Application
App = Interface + Data + Logic

The logic of an app is always code. The difference is where the code runs. Simple logic can run as script in an HTML file or in a Copilot Page, in the browser. When the logic must reach organizational data, it needs a runtime. For apps from Cowork, Copilot Studio or Copilot Code, this runtime is Copilot Managed Runtime.

Self-contained: the logic runs in the browser

Governed app: the runtime is between the logic and the data

Copilot Managed Runtime

Hosted by Microsoft · Microsoft Entra sign-in · DLP, conditional access, sharing limits · 1,500+ connectors · admin inventory

↓ permissions of the signed-in user

Data

Stays in its sources, for example SharePoint lists, Dataverse tables and other connected services

What Copilot Managed Runtime adds:

  • Identity — every app uses Microsoft Entra ID.
  • Data connections — the app uses the identity of the signed-in user. Sharing an app does not always share its data.
  • Shared data — the Cowork App skill can make a data schema in supported connectors. Copilot Studio makes a data model and manages the data and connections.
  • Governance — conditional access, data loss prevention (DLP), connector policies and sharing limits apply to every app. Every app shows in the admin inventory.

An app is not an agent. An agent decides what to do next (Module 8). A flow runs a designed path (Module 10). An app is what people select and use. A dashboard only reads and shows data (7.3.2).

11.3 Static and Interactive App

Copilot Code makes two kinds of app. A static app is a set of files that runs in the browser of the viewer. An interactive app is published to Copilot Managed Runtime. It signs users in and connects to organizational data.

11.4 Build Your App with Code

This is the deep dive for 6.2. You need an active Microsoft Copilot license and access to the Frontier preview program. Code works in the Microsoft Copilot desktop app and on the web (cloud only). Do these steps:

  1. Open the Microsoft Copilot app, or go to copilot.cloud.microsoft. Select Code in the tab switcher at the top.
  2. Select Create new to start a project.
  3. Describe the app. To add context, select + to upload files or attach your work context.
  4. Select where the project runs: on your device (local) or in the cloud. Select a model, or keep Auto (cloud only). Select a mode: Interactive (the default), Plan or Automatic.
  5. Look at the canvas next to the conversation. It shows the app while Code builds it.
  6. To change the app, describe the change or select an element on the canvas. To undo a change, ask Code to revert to an earlier version. Code saves the project automatically.
  7. To share a static app, share it as a link for your organization (cloud only). For the difference between a static app and an interactive app, see 11.3.
  8. To make an interactive app live, write “Publish it” or “Make it live”. Code publishes the app to Copilot Managed Runtime. Users open it at managedapps.cloud.microsoft.
  9. Share the published app with a link, as you share a document. Sharing an app does not share its data.
