Which tool should I use?

Copilot gives you a few different ways to work with a document — and the right one depends on what you're trying to do. Before you start, ask: how am I going to use this file? Your answer points to the right tool. (The same thinking works for both Word .docx and Excel .xlsx.)

1
Make specific changes to the file itself
→ Edit with Copilot, right in the app
docx: fill a template, draft or rewrite a documentxlsx: build or edit the workbook, add formulas & charts
2
Get high-level analysis across several reports or datasets
→ The Analyst agent
docx: pull insights from multiple reportsxlsx: find trends across multiple datasets
3
Use the document(s) as a source to answer questions
→ Attach as a cloud file, or add as a Knowledge source
docx: one policy doc (attach) vs a SharePoint policy library (knowledge source)xlsx: one workbook (attach) vs a folder of data files (knowledge source) — xlsx suitability as grounding knowledge depends on the use case
4
Create a brand-new file from a conversation
→ The Word / Excel agent in M365 Copilot
docx: turn a discussion into a new documentxlsx: generate a new workbook from your ask

Scenario 3 is where Grounded Knowledge vs. Attached Cloud Files (Module 6) comes in — attach a file to read it closely, or use a knowledge source to search a whole library. If a task like this repeats, consider building an agent for it.
