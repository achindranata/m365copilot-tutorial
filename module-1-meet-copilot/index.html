1.2 Where to access it — three front doors

There are three ways to reach Copilot. Two are available to everyone with a Microsoft 365 sign-in; the third — Copilot working directly inside your documents — depends on your license label (see 1.3).

New name — Microsoft 365 Copilot is now Microsoft Copilot. Announced August 13, 2026 and rolling out from August 18, 2026 (mobile and web) and mid-September 2026 (Windows and Mac), with the web address moving to copilot.cloud.microsoft. Official announcement · Microsoft Support

1 · Web Browser

Go to copilot.cloud.microsoft (shortcut: m365copilot.com) in any browser, sign in with your work account, and start chatting — nothing to install.

Microsoft Copilot (Premium)

With a Premium license, Copilot works fully inside Word, Excel, PowerPoint and Outlook (some organizations also give Copilot Chat (Basic) users standard access in Word, Excel, PowerPoint and OneNote). Click the small Copilot button at the bottom-right of your document and the side pane opens — ready to draft, rewrite or analyze the file you have open.

Which one should I use? Start in the browser or the Copilot app for chatting, catching up and asking questions across your work — both are included with your sign-in. Use Copilot inside the Office apps when you want it to act on the document, spreadsheet, deck or email you're actively working on — full, priority access comes with Microsoft Copilot (Premium); some organizations also give Copilot Chat (Basic) users standard access.

1.2.4 What’s new in the Copilot app — Home, Code & Autopilot

Home is the new starting point in the Copilot app: Chat and Cowork on one screen. Switch between them in the prompt box, review recent activity and pick up work where you left off.

  • Office in Copilot — create and edit real Word, Excel and PowerPoint files side by side with Copilot; recent files sit in Library.
  • Code — describe a tracker, dashboard or app in plain language and Copilot builds it.
  • Autopilot (previously Scout) — an always-on agent with its own identity and memory that keeps working without waiting for a prompt.
  • Tasks (top right) tracks long-running Chat work; Plugins replaces Agents & Skills and Automations moves into the navigation pane.

Rolling out through the Frontier program from October 2026. Cowork, Code and Autopilot use Copilot Credits (see 1.3) — without a spending policy you’ll see Request access.

1.3 Copilot licensing — Basic, Premium (USL) and Copilot Credits (UBB)

Microsoft splits AI work in two. Everyday AI — summarizing, drafting, analysis — is covered by a fixed-price, per-user license (USL). Advanced AI — long-running agentic work and the newest frontier models — runs on usage-based billing (UBB) and consumes Copilot Credits.

IncludedCopilot Chat (Basic)With an eligible Microsoft 365 subscription — no add-on
  • Web-grounded chat with enterprise data protection
  • Work IQ limited to files you upload
  • Copilot Chat in Outlook
  • Agents grounded in instructions and public websites; Copilot Studio pay-as-you-go
