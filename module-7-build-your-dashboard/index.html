Module 7

Build Your Dashboard with Microsoft Copilot

Copilot can turn your data into a dashboard. Where you keep the dashboard changes how it works. In this module, you learn what a dashboard is. Then you learn why an .html file and an .aspx page work differently in OneDrive and SharePoint.

SourceIntroduction to dashboards for Power BI designers — Microsoft LearnModule 7 · 1 of 4
7.1 Anatomy of a Dashboard

A dashboard is one screen that shows your most important metrics. You use it to monitor your work at a glance. When the data changes, the dashboard shows the new data.

Dashboard = Data + Visuals

Power BI gives a good reference definition: “A Power BI dashboard is a single page, often called a canvas, that tells a story through visualizations.” Every dashboard has the same five layers. The data goes up from layer 1 to layer 5:

5

Delivery surface

Where people see the dashboard: the Power BI service, a SharePoint page, an HTML file, or a screen in an app

4

Visuals

KPI cards, charts, tables and filters. On a Power BI dashboard, these are tiles

3

Model & calculations

Tables, relationships, measures and KPIs. In Power BI, this is a semantic model

2

Connection & refresh

How the data comes in and how current it is: a live link, a scheduled refresh, an API call, or a one-time snapshot

1

Data sources

Excel workbooks in OneDrive or SharePoint, SharePoint lists, Dataverse, databases, on-premises systems

Identity & permissions

Applies to all layers: who can open the dashboard, and which data each viewer can see

Layer 2 is the important one. It decides if your dashboard shows live data or old data. It is also the layer where an .html file and an .aspx page are most different (see 7.2). Dashboard or report? In Power BI, a dashboard is one page and a report can have many pages. You cannot filter a dashboard. When you select a tile, Power BI opens the report behind it.

7.2 Comparison Table: .html vs .aspx in OneDrive/SharePoint

You may have prompted Copilot to turn [/your Excel file] into an interactive .html dashboard. Copilot makes one .html file, and the dashboard works in the Copilot preview. Then you save the file to OneDrive or SharePoint and open it there. The file downloads, or it shows its code as text. Also, the data in the file is a snapshot. It does not change when the workbook changes. This section tells you why.

  • .html — a standalone web file. The markup, the styles and the script are in one file. SharePoint and OneDrive do not run its script. They download the file or show its raw content.
  • .aspx — an ASP.NET page. The server runs the page and sends plain HTML to the browser. Modern SharePoint pages are .aspx files in the Site Pages library. You build them with web parts.
.html in OneDrive/SharePointA file in a library
.aspx in SharePointA page in Site Pages

What it is

A standalone web file: markup, styles and script in one file.

What it is

A SharePoint page (an ASP.NET page) that you build from web parts.

How it becomes HTML

It is HTML. The browser reads it as it is.

How it becomes HTML

SharePoint serves the page. Then the web parts show it in the browser.

Where the dashboard is

In the file, in a OneDrive or SharePoint library.

Where the dashboard is

In the Site Pages library of a SharePoint site.

Where the logic runs

In the script of the file. SharePoint and OneDrive do not run this script.

Where the logic runs

In the web parts. They run in the browser, as the signed-in viewer.

Viewer sign-in

None. The file must sign viewers in itself.

Viewer sign-in

None needed. SharePoint viewers are already signed in.

Live Excel data

The Microsoft Graph Excel API (.xlsx only). The file must do its own sign-in.

Live Excel data

No code: the File and Media web part shows the workbook. Custom code: a SharePoint Framework (SPFx) web part calls Microsoft Graph.

Admin control

An app registration in Microsoft Entra, and Microsoft Graph permissions.

Admin control

Site permissions. Admins approve SPFx Graph permission requests in the SharePoint admin center.

Best for

A portable snapshot that you can send or open anywhere.

Best for

A team dashboard that stays on the site and shows the workbook where it is.

Rule of thumb. Use an .html dashboard as a snapshot: the data is inside the file. To show live workbook data to a team, put the workbook on a SharePoint page (.aspx) with the File and Media web part.

7.3 Discussions
7.3.1 Why .html in SharePoint needs Graph API configured but .aspx does not

The answer is about who signs the viewer in. Live Excel data comes through Microsoft Graph. Microsoft Graph gives data only to a signed-in user with an access token.

.html file.aspx page
Who signs the viewer inNobody. The file has no host. Nothing signs the viewer in or gives its script a token.SharePoint. It serves the page to a viewer who is already signed in.
What you must configure1. Register an app in Microsoft Entra.
2. Sign the user in with the Microsoft Authentication Library (MSAL).
3. Call the Microsoft Graph Excel API for the workbook.		No code: add the File and Media web part. Custom code: an SPFx web part uses MSGraphClientV3. It “handles authenticating against the Microsoft Graph for you”.
Who can do itAn admin with the Application Administrator or Application Developer role registers the app.A site owner adds the web part. An admin approves SPFx Graph permission requests.

Sign-in does not give access to data. Microsoft Graph is also under the SPFx web part; SharePoint only does the sign-in. The viewer must have permission to the workbook, and the tenant must consent to the Graph permissions.

7.3.2 What makes an app different from a dashboard?

A dashboard reads and shows data. An app also writes and acts.

AspectDashboardApp
FormulaDashboard = Data + VisualsApp = Interface + Data + Logic
PurposeMonitor your most important metrics at a glance.Do a task: track work, collect information, manage requests.
Data directionReads. The visuals change when the data changes.Reads and writes. Users change forms, fields and records.
LogicCalculations: measures and KPIs.Business rules and actions.
InteractionView, and open the detail behind a visual.Enter data, select buttons, start actions.
Typical in Microsoft 365A Power BI dashboard or report, a SharePoint page with an Excel workbook, an HTML snapshot.A Cowork, Copilot Code or Copilot Studio app on Copilot Managed Runtime, or Power Apps.

An app can contain a dashboard. When people update data or start actions from the screen, it is an app. You build your own app with Microsoft Copilot in Module 11.
