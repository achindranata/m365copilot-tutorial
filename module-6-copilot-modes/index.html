Microsoft Copilot Modes: Cowork, Code, Autopilot

Microsoft Copilot has three modes for work that is larger than one chat answer. In Cowork, you give Copilot an outcome. In Code, you describe software. In Autopilot, you give an agent a role and a goal. All three use usage-based billing in Copilot Credits (see 1.3).

ModeYou give itIt gives youWhere you find it
Cowork 6.1An outcome. For example: “Get me ready for Thursday’s review.”Completed multistep work across your Microsoft 365 apps and files. Cowork asks for approval before it sends or changes anything.Home — select Cowork in the prompt box.
Code 6.2A description of the software that you want.Working software: apps, dashboards, internal tools, static websites, data transforms, automations and scripts.The Code tab in the Microsoft Copilot app.
Autopilot 6.3A name, a role and a goal.An agent that keeps working without a prompt each time. It keeps you informed and in control.The Autopilot tab in the Microsoft Copilot app.

6.1 Cowork

Cowork

The agent you hand an outcome rather than a question — it plans the steps, works across your apps for as long as the job takes, and checks with you before anything leaves the building.

Reaches for
Your Outlook, Teams, files and data — grounded in Work IQ, inside your own permissions
Trades
A single reply for a finished outcome — minutes to hours, running on its own
Gives you back
Real files in your OneDrive, a task you can reopen, and an approval gate before it sends

Cowork is the agentic side of Microsoft Copilot — you describe an outcome and it plans and carries out the steps for you, across your apps. You don’t build it: it’s a ready-made agentic system — open it from the prompt box in Home.

Example Use Case Prompt

Get me ready for Thursday’s quarterly review with Contoso: pull the last three months of email and Teams threads plus the files in /Contoso FY26, summarize the decisions and everything still open, draft a 10-slide deck ending on risks, put the follow-up actions in a table with owners, and save it all to my OneDrive — check with me before you send or share anything.

See it run: from a use case to an agent design and a dashboard. One prompt gives Cowork a Finance use case. Cowork reads the sources, builds an Excel workbook, an interactive solution architecture and an interactive finance dashboard, and then asks you before it emails the architecture.

How it’s designed. Cowork is a prebuilt, autonomous agentic system that takes action, not just chats. Grounded in your emails, meetings, chats, files and data via Work IQ, it works through a multi-step job across Outlook, Teams, Word, Excel and PowerPoint. Where Copilot Chat answers in a single turn, Cowork works over minutes to hours — asking for your approval before sensitive actions, running in a secure, isolated environment, and acting only within your own permissions. Getting access takes two things, not one: an active Microsoft Copilot license and usage-based (Cowork) billing enabled — the spending policy is an access control, not just a budget. Without one, you’ll see Request access.

Reach for Cowork when…

  • the task is multi-step and can run largely on its own (e.g. research → draft → compile → follow-up), not a single prompt;
  • it should work over your own Microsoft 365 data (Work IQ) and take real actions — send mail, post in Teams, build docs, manage files — each behind an approval;
  • you want a ready-made agent you can extend with up to 50 custom skills and Microsoft 365 App Store plugins & connectors, rather than building one in Agent Builder or Copilot Studio;
  • it should run on a schedule — recurring prompts such as a daily briefing or a follow-up sweep;
  • the work stays within one person’s identity and permissions, with you reviewing the result.

Where Cowork runs, how approvals work, and what else it can do
Where it runsYour browser at copilot.cloud.microsoft, the Copilot desktop app for Windows and macOS, the Copilot mobile app, and Outlook and Teams. You need a Microsoft Copilot license and a spending policy — without one, you’ll see Request access.
ApprovalsCowork asks before sensitive actions. Approve once, use Approve All when several are waiting, or skip similar prompts for the rest of the session. Review or revoke these choices under Permissions in the side panel; automated tasks can be pre-authorized when you create them.
What else it can doEdit an existing Word, Excel or PowerPoint file in OneDrive or SharePoint · start a task when a matching email or Teams message arrives · complete web tasks in Microsoft Edge on your device · generate images · run up to 25 scheduled prompts. Leave the model on Auto; reasoning effort defaults to Medium.

Custom skills — teach Copilot a task once

A skill is a modular capability you hand a session so it performs one specific task reliably and repeatably. It isn’t more knowledge and it isn’t another tool — it’s a packaged procedure, with the assets and scripts that procedure needs travelling alongside it. The one-line distinction worth remembering: an agent is the “who”; a skill is the “how”. Add a skill when a task must be done the same way every single time — your report format, your naming convention, your review checklist.

Where they live, and when they load. Custom skills are stored as SKILL.md files in your OneDrive at /Documents/Cowork/skills/ — up to 50 of them. Cowork discovers your skills at the start of each session, so a skill you add mid-session isn’t picked up until the next one. The same applies to plugins: removing one takes effect in the next session, never mid-flight. Skill scripts run in a temporary, isolated environment inside the Microsoft 365 service boundary, removed when the task finishes . When you create, update or validate a skill, Cowork returns a plain-language quality report — still review a new skill’s output like a colleague’s first draft. Each SKILL.md can be up to 1 MB, with up to 20 companion files (10 MB per skill); custom skills aren’t supported in Cowork on mobile. Skills you create in Copilot Chat also work in Cowork; Cowork skills appear in Chat when you share them.

Special tip — Design in Chat, deploy to Cowork

Make “design in Chat → deploy to Cowork” your default loop — the single biggest way to save Copilot Credits, and the engine behind tip 4. For any important, ambiguous or repeated task, work across two surfaces:

Design in Chat

Plan the steps, draft and tighten the prompt, and preview the deliverable’s content and structure — all covered by your Premium license (USL) on Auto — no Copilot Credits.

→
Deploy in Cowork

Paste the finished prompt into a Cowork session to run the real multi-tool, multi-source execution — sending, scheduling and building files across your data.

Iterate in Chat (covered by your Premium license on Auto) until the prompt is right, then let Cowork do the work that consumes Copilot Credits once. Promote winning prompts into a custom skill (tip 9) or a recurring scheduled prompt so a single design keeps paying off.

6.2 Code

Code is a separate tab in the Microsoft Copilot app, next to Chat and Cowork. The Code tab turns what you describe into working software. You describe the result in natural language. Code builds it and shows it on a canvas next to the conversation.

  • What it makes — apps, dashboards, internal tools, static websites, data transforms, automations and scripts.
  • Where it runs — on your device, in a project folder that you select, or in a secure, isolated environment in the cloud. On your device, Code asks for your approval before it goes outside that folder, makes a network connection or runs a terminal command.
  • Technology — Code uses the same underlying technology as GitHub Copilot. It runs in a sandboxed environment.
  • Publish — a static app is shared as a link for your organization. An interactive app is published to Copilot Managed Runtime (see 11.3).
  • Control — admins can audit the actions of Copilot Code: the code that it generated, the commands that it ran, and the files that it read or wrote.

License and status. The Microsoft Copilot license controls access to Copilot Code. Usage counts against your Microsoft Copilot entitlement, and admins can set a spend limit for each user. Copilot Code is in the Frontier preview program. Deep dive: to build an app with Code, step by step, go to 11.4.

See it run: from a prompt to a live app. One prompt in the Code tab builds an approval app on a SharePoint list. Code plans, asks before it uses the data, builds with a live preview, then publishes the app to Copilot Managed Runtime when you ask. Microsoft’s own introduction is the video Meet Code in Copilot.

6.3 Autopilot

Autopilot (previously Scout) is a personal, proactive and persistent agent in the Microsoft Copilot app. Other modes wait for your prompt. Autopilot works without a prompt each time.

  • Start it — give it a name, a role and a goal. Then it goes to work.
  • Its own identity — it lives in your tenant with its own identity, memory, computer and workspace.
  • Where it works — in Teams, Outlook, chats, channels and documents. You can @mention it like a colleague.
  • Example — set up and manage a full supplier review process.
  • You stay in control — you set the objective and the boundaries. Sensitive actions can require your approval before they continue. Microsoft Purview policies apply.

Availability. Autopilot is in preview through the Frontier program. You must sign up and accept the terms of participation. You must have an active Microsoft Copilot license. Autopilot uses Copilot Credits; it stays off until your admin creates a spending policy.
